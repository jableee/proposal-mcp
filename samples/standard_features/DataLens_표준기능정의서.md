# DataLens 데이터포털 표준 기능 정의서

작성: 솔루션개발팀 / 버전 3.2
이 문서는 DataLens를 별도 개발 없이 설치했을 때 제공되는 기능을 정리한 것입니다. 제안서를 쓸 때 여기에 없는 내용은 표준 기능으로 약속하지 말고 개발팀과 먼저 협의해 주세요.

## 메타데이터 수집

Oracle, PostgreSQL, MySQL, MSSQL 네 가지 DB는 커넥터를 기본으로 제공합니다. 접속 정보만 등록하면 테이블, 컬럼, 코멘트를 정해 둔 주기(보통 매일 새벽)에 자동으로 수집합니다.
수집이 실패하면 자동으로 다시 시도하고, 그래도 실패하면 관리자 화면의 수집 이력에 남습니다. 급할 때는 화면에서 즉시 수집을 눌러 바로 다시 돌릴 수 있습니다.
CSV나 엑셀 파일은 사용자가 직접 올려서 데이터셋으로 등록할 수 있습니다. 위 네 가지 외의 DB(예: Tibero, SAP HANA)는 커넥터를 따로 만들어야 합니다.

## 통합검색

테이블, 컬럼, 표준용어, 게시글을 검색창 하나에서 찾을 수 있습니다. 유형별 필터와 정렬, 자동완성을 지원합니다.
업무 용어로 검색해도 표준용어에 연결된 테이블이 함께 나오기 때문에, 물리 테이블명을 몰라도 찾을 수 있습니다. 검색엔진은 Elasticsearch를 쓰며, 자산 수십만 건 기준으로 보통 1초 안팎에 결과가 나옵니다.

## AI 검색 (옵션 모듈)

"연체 관련 데이터 보여줘"처럼 문장으로 물어보면 질문을 해석해서 관련 데이터를 찾고, 근거가 된 데이터와 함께 요약해 줍니다.
옵션 모듈이라 별도 라이선스가 필요하고, 고객사가 쓰는 LLM을 연결해야 합니다. OpenAI 호환 API를 제공하는 사내 LLM이면 붙일 수 있어서 인터넷이 안 되는 폐쇄망에서도 동작합니다.

## 데이터 카탈로그와 오너십

데이터셋마다 설명, 컬럼 정의, 데이터 오너, 갱신 주기, 샘플 데이터를 볼 수 있습니다.
오너는 지정하고 다른 사람에게 넘길 수 있고, 퇴직자가 맡던 데이터셋은 관리자가 한 번에 이관할 수 있습니다.

## 표준용어와 표준코드 관리

표준단어, 표준용어, 표준도메인, 공통코드를 등록하고 고칠 수 있으며, 바뀐 내용은 이력으로 남습니다.
금융권 표준용어처럼 고객사가 이미 가진 목록은 엑셀로 한 번에 올릴 수 있습니다.

## 데이터 품질 진단

NULL 비율, 허용값, 중복 같은 규칙을 정해 두면 하루 한 번 배치로 진단하고 결과 리포트를 만듭니다.
진단은 배치로만 돌기 때문에 분 단위의 실시간 감시는 하지 않습니다. 실시간 감시가 필요하면 별도 모니터링 제품과 함께 제안하는 것이 맞습니다.

## 권한과 로그인

사용자 그룹과 역할로 메뉴와 데이터셋 접근 권한을 나눕니다. 권한이 없는 데이터셋은 목록에는 보여도 내용은 볼 수 없습니다.
컬럼 값 단위로 가리는 마스킹 기능은 표준에 없습니다. 개인정보 컬럼을 권한별로 가려야 한다면 마스킹 규칙과 적용 로직을 추가로 개발해야 합니다.
로그인은 SAML 2.0이나 OIDC를 지원하는 사내 SSO와 연동할 수 있습니다. 이 두 표준을 쓰지 않는 자체 인증 방식은 연동 개발이 필요합니다.

## 데이터 이용 신청과 승인

사용자가 데이터 이용을 신청하면 지정된 승인자가 포털 안에서 승인하거나 반려합니다. 여러 단계 승인도 설정할 수 있고 승인 이력이 남습니다.
결재는 포털 안에서만 이뤄집니다. 사내 그룹웨어 전자결재로 올리고 그 결과를 받아오려면 그룹웨어 API에 맞춘 연동 개발이 필요합니다.

## 데이터 분석과 리포트

SQL을 모르는 사용자도 화면에서 끌어다 놓는 방식으로 집계, 조인, 필터를 걸어 조회할 수 있고, SQL을 아는 사용자는 SQL 모드를 쓰면 됩니다. 결과는 엑셀로 내려받을 수 있습니다.
분석 결과는 리포트로 저장해 다른 사람과 공유할 수 있고, 남의 리포트를 가져와 고쳐 쓸 수도 있습니다.

## 알림

신청, 승인, 수집 실패 같은 일이 생기면 메일(SMTP)로 알려 줍니다. 사내 메신저 알림은 표준에 들어 있지 않아서, 메신저가 제공하는 API에 맞춰 연동해야 합니다.

## 사용 이력과 감사 로그

로그인, 조회, 다운로드 이력을 모두 저장하고 관리자 화면에서 검색할 수 있습니다. 보관 기간은 설정으로 정하며 기본값은 1년입니다.

## 설치와 이중화

컨테이너(Docker) 기반으로 설치하고, 폐쇄망 설치도 지원합니다. 서버 여러 대를 Active-Active로 묶을 수 있어 한 대가 멈춰도 서비스는 계속됩니다. 이때 수집 같은 배치 작업이 여러 서버에서 중복으로 도는 일은 막혀 있습니다.

## 화면과 접속 환경

웹 브라우저로 접속하며 PC 화면에 맞춰져 있습니다. 모바일 전용 앱은 없고, 모바일 브라우저에서도 화면 최적화는 되어 있지 않습니다.

## 현황 대시보드

데이터 자산 수, 수집 현황, 사용 현황을 한 화면에서 요약해 보여 줍니다.
